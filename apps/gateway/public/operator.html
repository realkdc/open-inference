How to bring a computer online

  1. Send a trusted host the app for Apple Silicon Mac, Windows x64, or Linux x64. MeshLLM is included. A website/API invite is not needed to donate compute.
  2. They open it and send you their public Owner ID. Approve it above, then privately give them the beta server address and contributor join code.
  3. They choose a model pool and click Start sharing. The app checks memory and downloads model pieces. One computer is the coordinator for each model; helpers choose worker.
  4. MeshLLM connects the computers and assigns model layers. A connected computer is not automatically a serving model; wait until the model shows ready here.
  5. API users can create a community key before then. Requests return unavailable until a complete model is ready; they never switch to the private pool.

A join code is not an approval check. Do not share it broadly. Hosts that run model stages can inspect the prompts or intermediate data they process.
