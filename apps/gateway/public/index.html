Want to contribute a computer?

Installing the host app does not start sharing. It includes MeshLLM, lets you choose which model pool to help, and sets a safe memory limit for your computer. You still press Start sharing yourself.

The app shows your public MeshLLM Owner ID first. Send it to the beta operator for approval; the app will not join until that ID is on the approved list.

The app offers Qwen3 8B as the starter pool and a larger Qwen3 30B-A3B pool. Each needs its own group of computers; the larger pool needs substantially more shared capacity.
