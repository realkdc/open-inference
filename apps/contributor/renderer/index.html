2. Join the shared pool

The beta administrator gives you a mesh join token.

02

If no computer is running this model yet, choose Start this model pool. That computer is the coordinator. Every additional computer chooses Join an existing model pool. All computers helping with the same model must select the same model and join token.

Starting a pool does not mean the model is ready yet. The coordinator and enough worker computers must connect and load their model stages before the API can answer requests.

The app starts with a 2,048-token context and automatically limits model memory. Only the computer chosen for this model should use coordinator mode.

What this does: MeshLLM connects computers and can split supported models into stages. Your computer may receive only some layers, but a working model package and compatible hardware are still needed. A weak or distant connection can make replies slow. The first trial works best with a few computers near one another.
Network reachability: peers need to reach this computer for split-stage traffic. On macOS, allow incoming connections for MeshLLM and turn off firewall stealth mode. A computer can look connected while its firewall still blocks its model stage.
Privacy: encrypted links protect data in transit. The first computer running the model receives the prompt. Other computers may receive intermediate model data. A worker owner could inspect what their computer is processing; this app cannot hide it from them. Mesh request logging is set to metadata only, but that does not prevent live inspection.
Network access: the app checks the beta server’s owner allowlist and starts MeshLLM in allowlist mode. The join token helps computers find the pool; it is not the approval check. Do not post it publicly.

3. Add an anonymous map dot (optional)

No precise location is requested or collected.

03
The map shows only a region bucket with 3 or more active host tokens, in a count range. Presence disappears within a few minutes after a computer goes offline. This token cannot run inference or view prompts.
Your computer stays yours. The worker uses your normal internet connection for mesh traffic. It does not create a whole-device VPN or make your internet connection faster. This build does not yet offer an exact bandwidth cap. Pause sharing to stop the worker; disconnect clears the join token from app memory.
